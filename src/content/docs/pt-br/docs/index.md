O Araru é um ecossistema open source e self-hosted para acervos digitais. Esta documentação cobre os produtos atuais Server e Web, conceitos operacionais, arquitetura e contribuição.

O Araru OSS não hospeda, fornece, distribui, vende nem mantém cópias de livros, quadrinhos, documentos ou qualquer outro arquivo lido pelo software. Cada instalação é executada na infraestrutura controlada pelo próprio usuário. O operador deve fornecer conteúdo adquirido legitimamente, manter os arquivos originais e backups independentes e decidir quem pode acessar o acervo em sua própria rede.
