**Status: fundação estável**

O cliente React/Vite oferece setup, login, biblioteca, categorias, busca, administração, offline e leitores internos de PDF, EPUB, MOBI, CBZ e CBR.

Toda comunicação usa `VITE_API_URL`. O Web não acessa diretamente PostgreSQL, Redis, filesystem, Drive, R2 ou segredos do servidor.
