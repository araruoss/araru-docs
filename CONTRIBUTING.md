# Contribuindo com o Araru

Obrigado pelo interesse em contribuir.

1. Leia o [contexto do projeto](src/content/docs/docs/project-context.md), as [invariantes](src/content/docs/docs/llm/constraints.md) e o [protocolo de mudança](src/content/docs/docs/llm/change-protocol.md).
2. Abra uma discussão/issue para mudanças arquiteturais ou de contrato.
3. Faça alterações pequenas e preserve dados, IDs, migrations e Range.
4. Adicione testes proporcionais e atualize a documentação.
5. Execute `npm run check` e `npm run build`; valide navegação, tradução e responsividade quando alterar layout ou conteúdo global.

Não inclua conteúdo protegido, credenciais, banco, livros ou caches no commit. Decisões significativas exigem ADR. O projeto é distribuído sob AGPL-3.0-only.
