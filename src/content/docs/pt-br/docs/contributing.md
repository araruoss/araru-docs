---
title: Como contribuir
description: Issues, pull requests, testes, traduções e segurança.
---

Use uma branch específica `feature/*` ou `fix/*`, explique o comportamento e os riscos no pull request e adicione testes proporcionais à mudança. Mantenha os commits revisáveis e não misture dados gerados, bibliotecas pessoais, segredos ou refatorações não relacionadas.

A documentação e as traduções passam por revisão de código. Mantenha os mesmos slugs entre os idiomas e nunca apresente um comportamento planejado como estável. Relate vulnerabilidades de forma privada conforme o `SECURITY.md` de cada repositório, nunca por uma issue pública.
