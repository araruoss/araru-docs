The identity should never reduce legibility. Goal: WCAG 2.2 AA for interface and communication.

- Appropriate minimum contrast for text/controls;
- Visible focus not dependent solely on color;
- Keyboard navigation and logical order;
- Accessible names and support for screen readers;
- Respect for `prefers-reduced-motion`;
- Zoom/font scaling without clipping;
- Touch targets at least 44×44 CSS px;
- Light/Dark tested separately;
- Mascot/illustration with useful or decorative alt text;
- Reader prioritizes content and typographic preferences.

Logos/colors cannot be the only way to communicate state.
