Araru is an open-source, self-hosted digital library ecosystem. This documentation covers the current Server and Web products, operational concepts, architecture, and contribution workflow.

## Start here

- [Getting Started](getting-started/): run a complete installation and add content.
- [What is Araru?](concepts/what-is-araru/): understand the product and its principles.
- [Ecosystem](ecosystem/): learn the responsibilities of each repository.
- [Administration](admin/): users, profiles, settings, storage, jobs, and backups.
- [Architecture](architecture/): Server/Client boundaries, PostgreSQL, Redis, readers, and security.

Pages distinguish **stable**, **experimental**, and **planned** behavior. Android and Desktop are currently planned clients, not released functionality.
