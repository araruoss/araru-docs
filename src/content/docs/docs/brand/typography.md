Priorities: legibility, availability, performance, accents, and extended reading.

- Display/Heading: system sans stack, weight 600–700;
- Body/UI: `Manrope`, `Avenir Next`, `Segoe UI`, sans-serif, using only locally available fonts;
- PDF/comics reader: original content;
- EPUB/MOBI reader: user preferences for family, size, height, and width.

There is no external font download. An official brand font is **TBD** and should be adopted only after evaluating its license, payload, and fallback.
