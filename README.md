# Araru Documentation

Documentation for users, contributors and maintainers across Araru Server, Web, Android and Desktop.

```bash
npm ci
npm run check
npm run build
npm run dev
```

Markdown sources live in `docs/`. Local links are checked before VitePress builds the static site. Pushes to `main` deploy to GitHub Pages. Product repositories are independent:

- [Araru Server](https://github.com/araruoss/araru-server)
- [Araru Web](https://github.com/araruoss/araru-web)
- [Araru Android](https://github.com/araruoss/araru-android)
- [Araru Desktop](https://github.com/araruoss/araru-desktop)

See [CONTRIBUTING.md](CONTRIBUTING.md).
